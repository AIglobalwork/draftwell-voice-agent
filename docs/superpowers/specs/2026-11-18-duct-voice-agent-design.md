# Голосовий агент запису для компанії з чистки вентиляції (США)

Дизайн-документ · 2026-11-18 · статус: на погодженні

## 1. Навіщо це

Портфоліо-проєкт на GitHub, який показує, що автор уміє працювати ШІ-інтегратором: вбудовувати ШІ в реальні процеси бізнесу, щоб клієнту було простіше записатися, а персоналу було менше рутини.

**Хто дивиться:** технічна людина, яка наймає (рекрутер, тімлід). Вона оцінює дві речі:
1. Якість коду: структуру, тести, історію комітів.
2. Процес роботи з ШІ-агентом (Claude Code): специфікації, плани, CLAUDE.md, осмислені коміти, чесний опис того, де агента довелося виправляти.

**Бізнес-проблема:** американські компанії з чистки повітропроводів часто не беруть трубку (бригада на виклику, вечір, вихідні) і втрачають клієнтів. Клієнт дзвонить наступній компанії зі списку.

**Строк:** 7 днів. **Бюджет:** $0 на розробку, резерв $5–10 на крайній випадок. Голос працює на кредитах LiveKit Inference тарифу Build: $2.50 на місяць, приблизно 50 хвилин, жорсткий ліміт без доплат. Тому голос лише для ручних перевірок і демо-відео.

## 2. Що робить система

```
Клієнт дзвонить (кнопка на демо-сторінці; бонус: справжній номер США)
        ↓
Голосовий агент відповідає від імені компанії (англійською)
        ↓
Розпитує: що треба, адреса/ZIP, кількість систем і решіток, додаткові послуги
        ↓
Перевіряє зону обслуговування → рахує орієнтовну ціну → шукає вільні слоти
        ↓
Узгоджує час, підтверджує деталі, створює запис у Google Calendar
        ↓
Клієнту: email-підтвердження + SMS (у демо показується, а не надсилається)
Власнику: повідомлення в email і Slack
```

## 3. Цілі, нецілі, антицілі

**Цілі**
- Агент доводить розмову до запису в календарі без участі людини.
- Слоти реальні: агент бачить лише вільний час із Google Calendar, подвійний запис неможливий.
- Ціну рахує код за прайсом, модель лише збирає дані й викликає функцію.
- Ціна завжди звучить як попередня оцінка: «Орієнтовно $520, точну суму технік підтвердить на місці».
- Перевірка зони обслуговування за ZIP-кодом.
- Якщо клієнт просить живу людину: агент приймає повідомлення і передає власнику.
- Рекрутер може спробувати агента сам (кнопка в браузері) і подивитися відео на 1–2 хвилини.
- Односторінковий сайт вигаданої компанії «з нуля» (послуги, ціни «від», зона обслуговування, як проходить чистка, FAQ, контакти) з кнопкою «Talk to our AI assistant». Сайт замінює окрему демо-сторінку. Головний спосіб запису на сайті: голосом через агента (рішення автора). Дизайн погоджується з автором на макетах до написання коду.

**Якщо лишиться час (рішення автора)**
- Повноцінний багатосторінковий сайт.
- Запис через текстовий чат на сайті.

**Пріоритет:** головне в проєкті агент. Якщо до кінця 5-го дня він не працює від дзвінка до запису в календарі, сайт спрощується до мінімуму.
- Репозиторій показує процес агентного програмування.

**Нецілі (свідомо не робимо за цей тиждень)**
- Перенесення та скасування записів.
- Консультації щодо плісняви, ремонту, якості повітря. Агент відповідає: «Технік оцінить на місці».
- Мови, крім англійської.
- Справжня відправка SMS (див. обмеження 10DLC).
- Інтеграції з галузевими CRM (Jobber, Housecall Pro).

**Антицілі (провал, навіть якщо технічно працює)**
- «Чат-бот, що пересилає текст у модель»: без справжніх інструментів і даних.
- Агент називає ціну, слот або послугу, яких немає в даних.
- Подвійний запис на один час.
- Демо, яке не працює, коли рекрутер натискає кнопку, і немає відео як запасного варіанта.
- API-ключі чи секрети в репозиторії.
- Вигадані відгуки клієнтів на сайті.
- Код, який автор не може пояснити на співбесіді.

## 4. Обмеження

- **SMS у США:** для будь-яких SMS із застосунку через 10-значний номер потрібна реєстрація A2P 10DLC з податковим ID компанії. Варіант Sole Proprietor доступний лише відправникам із США та Канади. Тому код відправки SMS через Twilio пишеться повністю, але вимкнений прапорцем (`SMS_ENABLED=false`). У демо текст SMS показується на сторінці. README пояснює чому.
- **Безкоштовні тарифи:** LiveKit Cloud Build (1000 хвилин агента на місяць, без картки, один безкоштовний номер США, холодний старт); Gemini Live через LiveKit Inference ($2.50 кредитів на місяць, приблизно 50 хвилин). Назва голосової моделі в одному значенні `VOICE_MODEL` у `.env`, щоб її можна було замінити.
- **Результат перевірки першого дня (19.11):** Gemini Live недоступна для ключа AI Studio: прямий плагін Google дає HTTP 404. Через LiveKit Inference (`google/gemini-3.8-live`, голос Puck, шумозаглушення ai-coustics) агент відповідає голосом. Рішення: голос через LiveKit Inference точно як у перевірці; ключ AI Studio (безкоштовний тариф) лише для текстових тестів розмов.
- **Текстова модель для тестів (перевірено 19.11):** `gemini-2.5-flash` закрита для нових користувачів; `gemini-3.5-flash-lite` відповіла; `gemini-3.8-flash` існує, але відповідала 503 «high demand». Назва моделі в `TEST_LLM_MODEL` (за замовчуванням `gemini-3.5-flash-lite`; `gemini-3.8-flash` як варіант, коли перестане повертати 503).
- **Ліміти публічного демо під 50 хвилин на місяць:** дзвінок до 5 хвилин (300 с); денного ліміту дзвінків немає. README і сайт кажуть, що в живого демо малий місячний бюджет голосу, а головне демо — відео. Коли кредити вичерпано (агент не відповідає), сайт пише, що живе демо на паузі, і показує відео.
- **Компанія вигадана.** Назва й бренд не повинні збігатися з реальною компанією. На демо-сторінці напис: «Fictional company, demo only».
- Автор лише починає вчитися агентному програмуванню, тому код має бути простим для читання й пояснення. Жодних зайвих абстракцій.

## 5. Підходи, які розглядали

| Підхід | Плюси | Мінуси |
|---|---|---|
| A. Vapi + власний сервер інструментів | Найпростіше, готова кнопка дзвінка, популярне серед інтеграторів | Лише $5–10 стартових кредитів, далі приблизно $0.08–0.13/хв; логіка в їхній панелі, у репозиторії менше видно |
| **B. LiveKit Agents + Gemini Live** ✅ | Увесь агент у коді репозиторію; $0 на безкоштовних тарифах; впізнаваний фреймворк (на ньому працює голосовий режим ChatGPT) | Складніше; ліміти free tier не гарантовані; холодний старт |
| C. Повністю локально (Whisper + Ollama + локальний TTS) | $0 назавжди | Локальні моделі погано викликають інструменти, а на цьому тримається вся ідея; рекрутер не зможе подзвонити |

**Обрано B** (рішення автора), бо він дає найбільше видимої роботи в репозиторії за нульового бюджету.

## 6. Рішення, ухвалені автором

- Голосовий агент веде клієнта до запису: перевіряє слоти, узгоджує час, записує.
- Після запису: SMS клієнту й повідомлення власнику.
- Слоти зберігаються в Google Calendar.
- SMS: код є, але вимкнений; у демо показується журнал SMS.
- Повідомлення власнику йдуть двома каналами: email і Slack.
- Рекрутер пробує агента через кнопку в браузері й відео; справжній номер США як бонус.
- Агент має доступ до прайсу й рахує загальну ціну під потреби клієнта.
- Ціна подається як попередня оцінка.
- Прайс вигаданої компанії з реальними цифрами ринку, в окремому файлі.
- Межі: перевірка ZIP і передача повідомлення живій людині входять у проєкт.
- Підхід B: LiveKit Agents + Gemini Live (через LiveKit Inference після перевірки першого дня).
- Слот 4 години з запасом на дорогу.
- Сайт компанії пишемо самі, дизайн погоджуємо на макетах. Обрано напрям «Фургон майстра» (B): темно-зелений #0D4A42, жовтий #F5C518, шрифти Barlow Condensed + Barlow, на першому екрані макет розмови з агентом, що закінчується записом. До цього напряму додано приклад розрахунку ціни по рядках (з напряму C).
- Місто: Атланта, штат Джорджія.
- (19.11) Голос через LiveKit Inference, як у робочій перевірці; модель в одному значенні `VOICE_MODEL`. Бюджет приблизно 50 хвилин на місяць, тому голос лише для ручних перевірок і демо-відео.
- (19.11) Тести розмов на текстовій моделі Gemini через ключ AI Studio (`GOOGLE_API_KEY`, безкоштовний тариф), а не через LiveKit Inference, щоб не витрачати голосові кредити.
- (19.11) Захист від подвійного запису без блокування в процесі (сесії можуть іти в різних процесах): див. розділ 7.
- (19.11) Денного ліміту сесій немає; дзвінок до 300 с.
- (19.11) Агент розгортається в LiveKit Cloud одразу після того, як запрацює локально. Деплой через ключі проєкту, бо `lk cloud auth` не працює на Windows.
- (19.11) README прямо каже, що в живого демо малий місячний бюджет голосу, а головне демо — відео.

## 7. Рішення Claude (автор може змінити)

- **Мова:** Python (основна для LiveKit Agents, найлегше читати й пояснювати).
- **Арифметика лише в коді:** функція `calculate_quote(...)` повертає суму й розбивку. Модель її не перераховує.
- **Прайс** (у межах ринкових діапазонів Housecall Pro 2026), файл `config/pricing.yaml`:
  - Чистка однієї системи: $449, включає до 10 решіток
  - Кожна додаткова решітка: $35
  - Друга й наступні системи: $349 кожна
  - Чистка вентиляції сушарки: $129
  - Антимікробна обробка: $99 за систему
  - Чистка вентилятора (blower): $179 за систему
- **Якщо клієнт не знає кількості решіток:** агент питає площу будинку, і код оцінює кількість решіток за простою таблицею (наприклад, до 1500 sq ft → 10, до 2500 → 14, більше → 18). Ціну тоді прямо називає «приблизною».
- **Розклад:** одна бригада; робочі дні пн–сб; кожен слот 4 години з запасом на дорогу (рішення автора); два слоти на день, 8:00–12:00 і 13:00–17:00, з годинною перервою між ними (рішення Claude, щоб робочий день не виходив за 17:00); часовий пояс міста компанії. Записувати можна від наступного дня до 14 днів наперед. Усе в `config/business.yaml`.
- **Компанія:** Draftwell (компанії з такою назвою в галузі не знайдено), телефон на сайті (404) 555-0142 з діапазону вигаданих номерів.
- **Зона обслуговування:** ZIP-коди Атланти, Decatur, Brookhaven, Sandy Springs, Dunwoody і Smyrna, у конфігурації. Часовий пояс America/New_York.
- **Захист від подвійного запису (рішення автора 19.11):** без блокування в процесі, бо сесії можуть іти в різних процесах. Перед записом код перевіряє, що слот вільний; після створення події перечитує події цього слота. Якщо їх більше однієї і наша не найраніша (за часом створення), код видаляє нашу подію, і агент каже клієнту, що час уже зайнято, та пропонує інші. На це є тест.
- **Доступ до календаря:** сервісний акаунт Google, з яким поділено календар компанії.
- **Журнал SMS і повідомлень на демо-сторінці:** агент передає текст SMS клієнту та повідомлення власнику на сторінку через канал даних LiveKit. Сторінка показує їх у бічній панелі («телефон клієнта» і «телефон власника») одразу під час дзвінка. Окрема база даних не потрібна.
- **Дані від клієнта:** ім'я, телефон, email, адреса з ZIP, кількість систем, решіток (або площа), додаткові послуги, бажаний час. Агент повторює ключові дані перед записом.
- **Email клієнта необов'язковий.** Агент просить продиктувати його по літерах і повторює перед записом. Без email клієнт отримує лише «SMS» у демо-панелі.
- **Захист публічного демо:** окремий демо-календар (не особистий календар автора); дзвінок обмежено 5 хвилинами (300 с). Денного ліміту сесій немає (рішення автора 19.11).
- **Агент представляється як віртуальний асистент**, а не людина.
- **Мова документації в репозиторії:** англійська (README, специфікації, коментарі). Цей документ українською для погодження; англійська версія потрапляє в репозиторій першого дня.

## 8. Як показується агентне програмування

- `CLAUDE.md` з правилами проєкту для агента.
- `docs/specs/` і `docs/plans/`: цей дизайн і план реалізації.
- Невеликі осмислені коміти, кожен закриває один крок плану.
- Розділ README «How this was built with Claude Code»: як ішла робота, де агент помилявся і як це виправлено, що автор вирішував сам.

## 9. Як перевіряється, що працює

- **Модульні тести** (pytest): розрахунок ціни, оцінка решіток за площею, перевірка ZIP, пошук вільних слотів, захист від подвійного запису, зокрема коли інша сесія створила подію в той самий слот трохи раніше (календар у тестах підмінено).
- **Тести розмов**: сценарії «звичайний запис», «не знає кількості решіток», «ZIP поза зоною», «хоче живу людину», «питає про плісняву», «просить знижку / ціну, якої немає». Перевіряємо, що агент викликав правильні інструменти й не назвав цифр, яких немає в результатах інструментів. Ці тести завжди запускаються з текстовою моделлю Gemini через ключ AI Studio (безкоштовний тариф), а не через LiveKit Inference, щоб не витрачати голосові кредити.
- **Ручна перевірка:** справжній дзвінок через демо-сторінку, запис з'являється в календарі, приходять email і Slack. Голосових дзвінків мінімум, бо бюджет приблизно 50 хвилин на місяць.
- **CI:** GitHub Actions запускає модульні тести на кожен push.

## 10. Що здається

- Публічний репозиторій GitHub з кодом агента, демо-сторінкою, тестами, конфігурацією, документацією.
- Сайт компанії на безкоштовному хостингу з кнопкою «Talk to our AI assistant» і бічною панеллю SMS/повідомлень.
- Агент розгорнутий у LiveKit Cloud, щоб рекрутер міг подзвонити без запущеного ПК автора.
- Відео 1–2 хвилини в README. Це головне демо, бо в живого демо малий місячний бюджет голосу; README каже про це прямо.
- Бонус, якщо лишиться час: справжній номер США від LiveKit.

## 11. Де що живе

| Частина | Де | Чому не GitHub |
|---|---|---|
| Код, документація, тести, CI | GitHub (репозиторій + GitHub Actions) | Це і є GitHub |
| Голосовий агент (Python, працює постійно) | LiveKit Cloud (безкоштовний Build) | GitHub не запускає сервери, які чекають на дзвінки |
| Сайт компанії + функція видачі токенів доступу | Netlify (безкоштовний тариф; планували Vercel, але він заблокував підтвердження телефону акаунта) | GitHub Pages віддає лише статичні файли, а токен треба підписувати секретним ключем, який не можна класти в код сторінки |
| Голосова модель, текстова модель для тестів, календар, email, Slack | LiveKit Inference, Gemini API (ключ AI Studio), Google Calendar, email-сервіс, Slack | Зовнішні сервіси |

Деплой на LiveKit Cloud і Netlify іде з того самого репозиторію.
